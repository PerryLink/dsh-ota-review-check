## 一、已取得逐字条文的文件

### 《中华人民共和国电子商务法》（2018 年 8 月 31 日第十三届全国人民代表大会常务委员会第五次会议通过）

- **来源**：中央网络安全和信息化委员会办公室（国家互联网信息办公室）
  <https://www.cac.gov.cn/2018-09/01/c_1123362506.htm>（新华社发布稿，全文三页，本次读到第一页）
- ⚠️ **本次只读到全文第一页**（第一至第四十六条）。本插件规则未涉及第四十六条之后的条款，
  但**若日后要引用第五章以后的内容，须先读第二、三页**。

与本插件直接相关的逐字条文：

> **第三十九条**　电子商务平台经营者应当建立健全信用评价制度，公示信用评价规则，为消费者提供对平台内销售的商品或者提供的服务进行评价的途径。
> 　　**电子商务平台经营者不得删除消费者对其平台内销售的商品或者提供的服务的评价。**

> **第十七条**　电子商务经营者应当全面、真实、准确、及时地披露商品或者服务信息，保障消费者的知情权和选择权。**电子商务经营者不得以虚构交易、编造用户评价等方式进行虚假或者引人误解的商业宣传，欺骗、误导消费者。**

> **第二十条**　电子商务经营者应当按照承诺或者与消费者约定的方式、时限向消费者交付商品或者服务，并承担商品运输中的风险和责任。

> **第三十一条**　电子商务平台经营者应当记录、保存平台上发布的商品和服务信息、交易信息，并确保信息的完整性、保密性、可用性。商品和服务信息、交易信息**保存时间自交易完成之日起不少于三年**。

## 二、⚠️ 核查推翻了本规则库原先的定性（重要）

规则库头部原先写：「其规范载体是《中华人民共和国电子商务法》**关于平台内经营者评价处理的规定**」。

**逐字核对后的结论：这部法律里没有"平台内经营者应当回复评价"的规定。** 相关条款的**义务主体是平台经营者**，
不是平台内经营者（即酒店／商家）：

| 条文 | 义务主体 | 义务内容 |
|---|---|---|
| 第三十九条第一款 | **平台经营者** | 建立信用评价制度、公示评价规则、为消费者提供评价途径 |
| 第三十九条第二款 | **平台经营者** | **不得删除**消费者评价 |
| 第十七条 | 电子商务经营者（含平台内） | 不得**编造**用户评价作虚假宣传 |
| 第二十条 | 电子商务经营者（含平台内） | 按承诺或约定的方式、时限交付商品或服务 |

因此：

1. **"平台内经营者应当回复点评"在本法中无明文依据** —— 回复义务来自**各平台的自身服务规则**
   （以及平台与商家的入驻协议），不属于这部法律。
2. **本插件核对的对象（商家是否回复、回复是否在时限内）因此是"平台规则 + 本机构管理口径"层面的事**，
   不是法律层面的强制义务。规则库头部与 README 已按此更正：**不再把"回复评价"说成法律要求**。
3. 反过来，**第三十九条第二款是平台经营者不得删评价** —— 这条与"商家回复"无关，
   本插件**不涉及**，也不应引用（引用会张冠李戴）。

**这一处更正是本次核查的实际收益**：原先的表述会让读者以为"不回复点评 = 违法"，而法律并未这样规定。

## 三、规则逐条核对结论

| 规则 | 核对后依据状态 |
|---|---|
| `OT-001` 记录内容与评分 | 依据为**台账齐备性**（功能前提），非法律条文。第二十条关于"按承诺交付"与评价内容无关，不引用。 |
| `OT-002` 已回复应记回复日期 | **本机构口径**：回复本身不是法定义务，故"记不记日期"更是本机构管理要求。`kind` 应体现为本地配置（见第四节）。 |
| `OT-003` 未回复的应在配置时限内 | **平台规则**。各平台时限不同（24 小时／48 小时／工作日／无强制），本插件不内置任何平台时限 —— 与逐字核对结论一致。 |
| `OT-004` 回复日期不早于点评日期 | **日期自洽**（功能前提）。 |
| `OT-005` 已回复应记录回复人 | **本机构口径**（责任落点）。 |
| `OT-006` 问题类型取值 | **本机构分类口径**，出厂为空。 |
| `OT-007` 点评编号唯一 | **台账唯一性**（功能前提）。 |
